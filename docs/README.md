# Guides

Interface walkthroughs for designers who are getting started with Git, GitHub, and Claude Code. You don't need to be a developer. Each guide explains the tool in plain language, walks through a real task step by step, and shows how to review and undo changes, including ones Claude Code makes.

Start here to find the right guide.

| Guide | Use it to |
| --- | --- |
| [GitHub Desktop](github-desktop/README.md) | Save versions of your work, try ideas on branches, and open pull requests without typing Git commands |
| [VS Code](vs-code/README.md) | Open a project, see what changed, and work with Claude Code in one window |

Looking for terminal commands instead? See the [CLI reference](../cli/README.md).

To add a guide, copy [`templates/guide-template.md`](../templates/guide-template.md) into a new folder here as `README.md`, then add a row to this table. The [templates README](../templates/README.md) has the full instructions and style rules.
